# Тестові дані

Усі дані, з якими виконувалось ручне тестування та на яких працюють автотести.
Файли лежать у [`test_data/`](../test_data); синтетичні набори для автотестів генеруються кодом
(`framework/data/`), щоб тести не залежали від стану сервера.

## 1. Стан застосунку

Застосунок зберігає точки в `localStorage` під ключем `agtech_monitoring_points_v1`.

### 1.3 Набір для автотестів — `standard_points`

`framework/data/datasets.py`: 5 точок `std-1…std-5` у 4 полях, усі 4 типи, дати 20–24.09.2026.
Точки розміщено далеко від центрів полів, щоб клік у центр (додавання точки) не влучав у маркер.
MGRS кожної точки рахується незалежним конвертером (`framework/utils/geo.py`).

## 6. Облікові дані

HTTP Basic Auth: логін `qa`, пароль — з умови завдання. У репозиторії не зберігаються:
задаються через `.env` (`APP_USERNAME`, `APP_PASSWORD`, див. `.env.example`) або секрети CI.
