## TC-01 Додавання точки в активному полі

**Передумови:** активне «Поле №1».

| # | Крок | Очікуваний результат |
| --- | --- | --- |
| 1 | Клікнути всередині полігона Поля №1 | Відкривається модалка «Додати моніторингову точку» з координатами WGS 84 (5 знаків) і MGRS |
| 2 | Звірити MGRS з координатами | MGRS відповідає координатам (похибка до 1 м через округлення) |
| 3 | Обрати тип «Шкідники», опис «QA: новий осередок шкідників» | Поля заповнено, помилок немає |
| 4 | Натиснути «Зберегти точку» | Модалка закрилася; точка перша в списку (сортування «Нові»), з типом, полем, MGRS; лічильники списку й поля +1; маркер на карті |
| 5 | Перезавантажити сторінку | Точка на місці (localStorage) |
